# Fast Download Manager

A fast, multi-connection download manager with browser integration and video capture.

This repository holds the releases, their notes and the website. Download the installer for your system
from [Releases](https://github.com/Naz-Ovh/Fast-Download-Manager/releases/latest).

| System | File |
| --- | --- |
| Windows 10/11 (x64) | `.msi` |
| Linux (x86_64, Wayland) | `.run`, `.deb`, `.pkg.tar.zst` |
| macOS | coming later |

What changed in each version: [changelog](changelog/), one file per version.

Website: <https://fdm.naz.ovh>

Found a problem? Open an [issue](https://github.com/Naz-Ovh/Fast-Download-Manager/issues).
