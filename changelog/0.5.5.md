# 0.5.5 - 2026-10-28

The first public release.

## Features

- **Fast downloads:** each file is split into parts downloaded over several connections at once, with pause, resume after a broken connection or a restart, automatic retries and a speed limit per download.
- **Browser extension** for Chrome, Edge and Firefox: takes over downloads from the browser and finds the videos on a page, with a download menu on the video and a list of the page's videos in the popup.
- **Video downloads:** HLS and DASH streams (including AES-128 encrypted HLS) saved as one file. Video and audio are merged into a single MP4 or MKV by the app itself, no extra tools needed. TS streams are saved as MP4.
- **Videos in site players:** every available quality, labelled with its real resolution.
- **Subtitles inside the video:** pick a language and the subtitles are added to the downloaded file as a track you can turn on and off; an option also saves them next to it as `.srt` files.
- **Download list** with categories, sortable columns and a right-click menu; a progress window that shows each connection's part; a "Download complete" window to open the file or its folder.
- **Command line:** `/d URL` with `/p` (folder), `/f` (file name), `/n` (no questions), `/a` (add to the list only) and `/q` (quit when done), for scripts and other programs.
- **39 languages**, the system language by default, with right-to-left layouts for Arabic, Hebrew and Persian.
- **Light and dark theme** that follows the system.
- **Windows installer (`.msi`):** install for you only or for everyone, upgrades in place, starts with Windows and waits in the tray.
- **Linux:** a `.run` installer that works on any distribution with glibc 2.31 or newer, a one-line install command, a `.deb` package for Debian and Ubuntu and a package for Arch. Wayland, with the app's own title bar and a tray icon.

## Fixes

- The app no longer freezes while large downloads are running.
- Setup no longer stops at "Starting" or "Computing space".
- A file is no longer written wrong when a server sends a different part than the one asked for.
- Compressed (gzip) downloads are saved unpacked, as the real file.
- Merging video and audio shows real progress and a steady time left.
- Windows: the system proxy is read without starting a hidden helper program, which some antivirus programs flagged.
- Linux: double-clicking the title bar maximizes the window, windows have a thin edge where the desktop draws no shadow, and the progress window is no longer cut off.
