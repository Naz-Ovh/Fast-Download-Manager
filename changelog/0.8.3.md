# 0.8.3 - 2026-11-26

Find your downloads faster, see how much you downloaded, and never download the same file twice by accident.

## Features

- **Duplicate downloads:** adding a link or file you already have asks what to do: add it with a numbered name, overwrite the old file, or resume it (or show it if it is finished). Choose a default in Options, in the app and in the browser extension.
- **Filters in All downloads:** filter the browser's download list by date (this month, last 7 or 30 days, a month or a custom range), size, site, type and status; active filters show as chips you can remove, and they stay after a reload.
- **Lighter download list:** the browser's list shows the newest 50 downloads with **Load more**, and a divider for each month, so long histories stay fast. Search now looks through every download.
- **Totals:** a small card above the list shows how much you downloaded and uploaded, for everything or for the current filter.
- **Seed when finished, per torrent:** turn seeding on or off for one torrent, from its menu or its details, in the app and in the browser.
- **Torrents folder:** new torrents are saved in a Torrents folder inside your Downloads folder by default; change it in Options → Torrents.
- **Torrent added:** after you start a torrent from the browser, a small message confirms it, with a button that opens All downloads (or switches to it if it is already open).

## Fixes

- The details panel in All downloads can no longer be dragged so wide that the list becomes unreadable.
