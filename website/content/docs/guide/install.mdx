---
title: Install
description: Install Fast Download Manager on Windows or Linux from the latest release.
---

Download the file for your system from the [latest release](https://github.com/Naz-Ovh/Fast-Download-Manager/releases/latest).
Each file holds the whole product: the app, the browser link, the `fdm` command line and the browser extension.
Nothing more is downloaded during setup.

## Windows

Windows 10 and 11, x64. Open `FastDownloadManager-<version>-x64.msi`.

- **Choose who gets it.** **Just me** installs for your account without administrator rights. **Everyone on
  this computer** installs for all users and asks for administrator rights.
- **Start with Windows.** On by default, so the app waits in the tray after you sign in. You can turn it off
  in the app's settings.
- **Connect your browsers.** The last setup page has a button that opens the extension folder. See
  [Browser extension](/docs/guide/browser-extension/).
- **Update in place.** Running a newer setup closes the app, replaces it and starts it again. Your settings and
  downloads stay.

## Linux

x86_64, Wayland desktops (KDE and GNOME first), glibc 2.31 or newer (Ubuntu 20.04, Debian 11 and later).

<Tabs items={['Any distribution', 'Debian, Ubuntu', 'Arch']}>
<Tab value="Any distribution">

```bash
sh FastDownloadManager-*.run
```

The setup asks **Just me** (no root, in your home folder) or **Everyone** (asks for your password).

</Tab>
<Tab value="Debian, Ubuntu">

```bash
sudo apt install ./fast-download-manager_*.deb
```

Remove it with `sudo apt remove fast-download-manager`; your settings and downloads stay.

</Tab>
<Tab value="Arch">

```bash
sudo pacman -U fast-download-manager-*.pkg.tar.zst
```

Remove it with `sudo pacman -R fast-download-manager`.

</Tab>
</Tabs>

The first start registers the browser link and adds the app to your session's autostart.
